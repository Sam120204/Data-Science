# Data Science

## Sentiment Analysis: Classic NLP vs. LLMs

Research into when classical sentiment methods remain useful in 2026, compared
with transformer classifiers and prompted LLMs. The project covers technical
mechanisms, comparative evidence, cost, latency, interpretability, and financial
applications.

**[Open the research overview](research/README.md)** for the findings, progress,
paper links, and runnable code.

The literature synthesis and initial baselines are implemented. Constructed-example
runs and automated checks are complete; representative-data benchmarks and LLM
experiments remain pending.
